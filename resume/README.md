# CV Project Entry

**ESP32 Thermostat — Embedded QA Case Study**

- Planned risk-based testing for an ESP32 thermostat in Wokwi, with eight quality risks and 13 test cases covering control, inputs, faults and recovery.
- Used Pytest, UART logs, a logic-analyzer trace and component checks to verify behavior; documented three reproducible defects.
- Recommended NO-GO because sensor failure can request heat, supported by linked evidence and acceptance criteria.

Tools: C++, Python, Pytest, PlatformIO, Wokwi, UART and Git.
